The Paul 50 Bag — plugin (test build)

Mac
1. Unzip.
2. Updating? First DELETE the old "The Paul 50 Bag.component" and ".vst3" (drag to Trash).
   Copying over an old version breaks its code signature and makes the DAW crash.
   Copy "The Paul 50 Bag.component" to  ~/Library/Audio/Plug-Ins/Components/
   Copy "The Paul 50 Bag.vst3"      to  ~/Library/Audio/Plug-Ins/VST3/
3. These test builds are not notarised yet. Once, in Terminal:
     xattr -cr ~/Library/Audio/Plug-Ins/Components/"The Paul 50 Bag.component" ~/Library/Audio/Plug-Ins/VST3/"The Paul 50 Bag.vst3"
   Or all in one go (Terminal, from the unzipped folder):
     P=~/Library/Audio/Plug-Ins; rm -rf "$P/Components/The Paul 50 Bag.component" "$P/VST3/The Paul 50 Bag.vst3"; cp -R "The Paul 50 Bag.component" "$P/Components/"; cp -R "The Paul 50 Bag.vst3" "$P/VST3/"; xattr -cr "$P/Components/The Paul 50 Bag.component" "$P/VST3/The Paul 50 Bag.vst3"
4. Restart your DAW and look for "SamSonight · The Paul 50 Bag" under instruments.
"The Paul 50 Bag.app" is a standalone version (no DAW needed).

In a DAW the band follows the host tempo and plays while the transport runs.
A MIDI note sets the key of the whole band.

Separate outputs (stems)
Besides the main mix the plugin has 5 extra stereo outputs: Bass, Lead, Drums, Pad, FX (reverb/delay returns).
- Logic: load it as "The Paul 50 Bag" Multi Output (Stereo), then press + on the instrument channel strip in the mixer to add the aux channels.
- Ableton: make new audio tracks, set "Audio From" to the Paul 50 Bag track and pick Bass / Lead / Drums / Pad / FX.
The main output always carries the full mix; mute or lower it when you work with the stems.
